항상 한국어로 답변한다. 영어 대신 한국어를 사용해야 한다.

**Why:** 사용자가 명시적으로 한국어로 번역해서 답변해 달라고 요청했고, 이후 작업에도 동일하게 적용해달라고 했다.

**How to apply:** 모든 텍스트 응답(설명, 요약, 상태 업데이트 포함)을 한국어로 작성한다. 코드 주석이나 코드 자체는 변경하지 않는다.
